# ADR-0001: Python 3.13 채택

- 상태: 채택
- 날짜: 2026-08-26

## 상황
로컬에 Python 3.13.9가 이미 설치돼 있는데, 로드맵 초안은 3.12로 적혀 있다.

## 후보
1. 3.12 재설치 — 로드맵 초안 표기에 맞춘다
2. 3.13 유지 — 기설치본을 그대로 쓴다

## 결정과 근거
3.13 유지.
- 주요 의존성(FastAPI·SQLAlchemy·Celery·asyncpg) 호환 확인
- 재설치 비용 절약 — 개발자 1명·10주라는 제약상 환경 재구성에 쓸 시간이 없다 (R3)
- 지원 기간 2029.10까지
- Dockerfile은 python:3.13-slim으로 정렬 예정 (로컬-컨테이너 버전 일치)

## 뒤집는 조건
세션 2 의존성 설치 실패 시 3.12로 복귀한다.
