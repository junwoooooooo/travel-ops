# ADR-0004: JWT 라이브러리는 PyJWT

- 상태: 채택
- 날짜: 2026-08-29

## 상황
로드맵 ADR #9에서 인증을 JWT로 정했다. 실제 서명·검증 라이브러리를 고를 차례다.

## 후보
1. python-jose — 과거 FastAPI 문서의 기본 선택
2. PyJWT — 현행 FastAPI 문서 선택
3. authlib

## 결정과 근거
PyJWT.
- python-jose는 유지보수가 사실상 멈췄고 과거 CVE 대응이 늦었다. 운영 인력 0명인 프로젝트에서 보안 패치를 스스로 감시해야 하는 의존성은 비용이다 (R3)
- 지금 필요한 기능은 HS256 서명·검증·만료뿐이라 authlib(OAuth 프로바이더 전체)은 과하다
- FastAPI 공식 예제와 같은 스택이라 참고 자료가 최신이다

## 뒤집는 조건
외부 IdP 연동(구글 로그인 등)으로 JWKS·OIDC 흐름이 필요해지면 authlib으로 옮긴다.
